# Weatherly – Weather App

A modern and responsive weather application built with **HTML, CSS, and JavaScript**.

## Features

* 🔍 Search weather by city
* 🌡️ Current temperature & weather condition
* 💧 Humidity, wind, pressure & visibility
* ☀️ Dynamic weather icons
* 📅 5–7 day daily forecast
* 🕐 Click a day to view hourly forecast
* 🌦️ UI changes based on sunny, rainy, cloudy, stormy & night conditions
* 🌙 Dark/Light mode
* 📱 Fully responsive design
* ⚠️ Loading and error handling

## Technologies

* HTML5
* CSS3
* JavaScript
* Weather API

## Project Structure

```text
Weatherly/
├── index.html
├── style.css
└── script.js
```

## Setup

1. Clone/download the project.
2. Add your weather API key in `script.js`.
3. Open `index.html` in a browser.
4. Search for any city.


Built as a frontend project using **HTML, CSS & JavaScript**.
